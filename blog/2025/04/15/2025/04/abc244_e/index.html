AtCoder ABC244 E - King Bombee 解説

April 15, 2025 · 7 min read
TAmemiya
Small fry IT technician

問題ページ: https://atcoder.jp/contests/abc244/tasks/abc244_e

提出コード: https://atcoder.jp/contests/abc244/submissions/64860247

方針​

動的計画法（DP）を用いて解きます。DPテーブルの状態として、「頂点 X を通過した回数の偶奇」を持つことで、問題の制約に対応します。

まず、「経路中に頂点 X(X≠S,T)X \left( X \ne S, T \right)X(X=S,T) を偶数回（000 回を含む）通る」という条件を無視して考えます。 この場合、問題は「無向グラフにおいて、頂点 SSS から出発し、KKK 回の移動後に頂点 TTT に到達する経路の総数を求める」ことと等しくなります。

移動回数を kkk、k−1k-1k−1 回の移動後に頂点 uuu にいる経路数を DP[k−1][u]DP[k-1][u]DP[k−1][u] とします。頂点 uuu に隣接する頂点を vvv とすると、kkk 回目の移動で uuu から vvv へ遷移する場合の DP テーブルの更新（遷移）は以下のようになります。 DP[k][v]=∑u∈adj(v)DP[k−1][u]DP[k][v] = \sum_{u \in \text{adj}(v)} DP[k-1][u]DP[k][v]=∑u∈adj(v)​DP[k−1][u] (ここで adj(v)\text{adj}(v)adj(v) は頂点 vvv に隣接する頂点の集合です。)

より具体的に、各頂点 uuu からその隣接頂点 vvv へ配る形式（実装でよく用いられる形式）で考えると、遷移は次のようになります。 DP[k][v]=(DP[k][v]+DP[k−1][u])(mod998244353)DP[k][v] = (DP[k][v] + DP[k-1][u]) \pmod{998244353}DP[k][v]=(DP[k][v]+DP[k−1][u])(mod998244353) (各 uuu から隣接する vvv へ、 DP[k−1][u]DP[k-1][u]DP[k−1][u] の値を加算していきます。計算結果は 998244353998244353998244353 で割った余りを求めます。)

入力例1について、この条件無視の場合の DP テーブル (DP[k][v]: kkk 回移動後に頂点 vvv にいる経路数) の値の遷移は以下のようになります。（表の横軸は移動回数 kkk、縦軸は頂点番号）

次に、「経路中に頂点 X(X≠S,T)X \left( X \ne S, T \right)X(X=S,T) を偶数回（000 回を含む）通る」という条件を考慮します。

この条件を扱うために、DP の状態を拡張します。具体的には、頂点 X を通過した回数の偶奇によって DP テーブルを分けます。

  • DP[0][k][v]: kkk 回移動後に頂点 vvv にいて、かつ経路中の頂点 XXX の通過回数が偶数であるような経路の数。
  • DP[1][k][v]: kkk 回移動後に頂点 vvv にいて、かつ経路中の頂点 XXX の通過回数が奇数であるような経路の数。 (実装では dp1 が DP[0], dp2 が DP[1] に相当します)

DP の遷移を考えます。k−1k-1k−1 回移動後、頂点 uuu にいる状態から、kkk 回目の移動で隣接する頂点 vvv へ移る場合を考えます。(MOD = 998244353 とします)

  • 移動先の頂点 vvv が XXX でない場合:
    • 頂点 XXX の通過回数の偶奇は変化しません。
    • 偶数状態からの遷移: DP[0][k][v]=(DP[0][k][v]+DP[0][k−1][u])(modMOD)DP[0][k][v] = (DP[0][k][v] + DP[0][k-1][u]) \pmod{MOD}DP[0][k][v]=(DP[0][k][v]+DP[0][k−1][u])(modMOD)
    • 奇数状態からの遷移: DP[1][k][v]=(DP[1][k][v]+DP[1][k−1][u])(modMOD)DP[1][k][v] = (DP[1][k][v] + DP[1][k-1][u]) \pmod{MOD}DP[1][k][v]=(DP[1][k][v]+DP[1][k−1][u])(modMOD)
  • 移動先の頂点 vvv が XXX である場合:
    • 頂点 XXX の通過回数の偶奇が反転します。
    • 奇数状態から偶数状態への遷移: DP[0][k][v]=(DP[0][k][v]+DP[1][k−1][u])(modMOD)DP[0][k][v] = (DP[0][k][v] + DP[1][k-1][u]) \pmod{MOD}DP[0][k][v]=(DP[0][k][v]+DP[1][k−1][u])(modMOD)
    • 偶数状態から奇数状態への遷移: DP[1][k][v]=(DP[1][k][v]+DP[0][k−1][u])(modMOD)DP[1][k][v] = (DP[1][k][v] + DP[0][k-1][u]) \pmod{MOD}DP[1][k][v]=(DP[1][k][v]+DP[0][k−1][u])(modMOD)

(これらの遷移を、全ての辺 (u,v)(u, v)(u,v) と偶奇の状態 p∈{0,1}p \in \{0, 1\}p∈{0,1} について行います。実装では、各頂点 uuu から隣接頂点 vvv へ配る形式で計算しています。)

最終的に求める答えは、KKK 回の移動後に頂点 TTT にいて、かつ頂点 XXX の通過回数が偶数である経路の数、すなわち DP[0][K][T]DP[0][K][T]DP[0][K][T] です。(実装における dp1[iK][iT] に相当します。)

実装​

public class Solve
{
    public static void Run()
    {
        var inputs = ReadLine.Ints();
        int iN = inputs[0], iM = inputs[1], iK = inputs[2], iS = inputs[3], iT = inputs[4], iX = inputs[5];
        var iUV = ReadLine.IntMatrix(iM);

        var modulus = 998244353L;
        var sug = new SimpleUndirectedGraph(iN, iUV);
        var dp1 = Matrix<long>.Create(iK + 1, iN + 1); // DP[0][k][v]: X偶数回
        var dp2 = Matrix<long>.Create(iK + 1, iN + 1); // DP[1][k][v]: X奇数回

        dp1[0][iS] = 1L; // 開始地点 S (0回移動) はX偶数回(0回)状態

        for (int k = 1; k <= iK; k++)
            for (int n = 1; n <= iN; n++)
            {
                // k-1 ステップ時点で頂点 n にいる各状態 (偶数/奇数) から、k ステップ目の状態へ遷移させる (配るDP)
                AddDp(dp1, dp2, k, n, sug, iX, modulus); // 偶数状態 (dp1[k-1][n]) からの遷移を計算
                AddDp(dp2, dp1, k, n, sug, iX, modulus); // 奇数状態 (dp2[k-1][n]) からの遷移を計算
            }

        Console.WriteLine(dp1[iK][iT]);
    }

    /// <summary>
    /// DPの遷移計算を行う (配るDP)。
    /// </summary>
    public static void AddDp(long[][] dp1, long[][] dp2, int k, int n, SimpleUndirectedGraph sug, long iX, long modulus)
    {
        if (dp1[k - 1][n] != 0L)
            foreach (var nv in sug.GetNeighbors(n))
                if (nv == iX)
                {
                    dp2[k][nv] += dp1[k - 1][n];
                    dp2[k][nv] %= modulus;
                }
                else
                {
                    dp1[k][nv] += dp1[k - 1][n];
                    dp1[k][nv] %= modulus;
                }
    }
}
